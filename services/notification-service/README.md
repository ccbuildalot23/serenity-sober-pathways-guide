# Serenity Notification Service\n\nA comprehensive, production-ready notification microservice built with Node.js, Express, TypeScript, and WebSocket support. Designed for HIPAA compliance and high availability.\n\n## 🚀 Features\n\n### Core Functionality\n- **Multi-channel Notifications**: In-app, email, SMS, WhatsApp, push notifications\n- **Real-time WebSocket**: Live notification delivery and crisis alerts\n- **Queue Processing**: BullMQ-powered job queues with retry logic\n- **Template System**: Reusable notification templates with variable substitution\n- **User Preferences**: Granular notification preferences and quiet hours\n- **Crisis Management**: High-priority crisis alerts with escalation\n- **Analytics & Reporting**: Delivery statistics and performance metrics\n\n### Security & Compliance\n- **HIPAA Compliant**: Comprehensive audit logging and data encryption\n- **JWT Authentication**: Secure token-based authentication\n- **Role-based Access Control**: Fine-grained permissions system\n- **Rate Limiting**: Per-user and global rate limiting\n- **Input Validation**: Comprehensive request validation with Joi\n- **Security Headers**: Helmet.js security headers\n- **Data Encryption**: AES-256-GCM encryption for sensitive data\n\n### Infrastructure\n- **Docker Support**: Multi-stage Dockerfile and docker-compose\n- **Health Checks**: Comprehensive health, readiness, and liveness endpoints\n- **Monitoring**: Prometheus metrics and Grafana dashboards\n- **Clustering**: Multi-worker support with graceful shutdown\n- **Error Handling**: Comprehensive error handling and logging\n- **Circuit Breakers**: Resilience patterns for external services\n\n## 🏗️ Architecture\n\n```\n┌─────────────────┐ Start\n\n### Prerequisites\n- Node.js 20+\n- Docker & Docker Compose\n- PostgreSQL 15+\n- Redis 7+\n\n### Development Setup\n\n1. **Clone and Install**\n   ```bash\n   cd services/notification-service\n   npm install\n   ```\n\n2. **Environment Configuration**\n   ```bash\n   cp .env.example .env\n   # Edit .env with your configuration\n   ```\n\n3. **Database Setup**\n   ```bash\n   # Run the migration script against your Supabase instance\n   psql -h your-db-host -U postgres -d serenity_db -f ../../supabase/migrations/20250122_notification_service_tables.sql\n   ```\n\n4. **Start Development Server**\n   ```bash\n   npm run dev\n   ```\n\n### Production Deployment\n\n1. **Using Docker Compose**\n   ```bash\n   # Set environment variables\n   export JWT_SECRET=\"your-jwt-secret\"\n   export SENDGRID_API_KEY=\"your-sendgrid-key\"\n   export TWILIO_ACCOUNT_SID=\"your-twilio-sid\"\n   export TWILIO_AUTH_TOKEN=\"your-twilio-token\"\n   \n   # Start all services\n   docker-compose up -d\n   ```\n\n2. **Health Check**\n   ```bash\n   curl http://localhost:3000/health\n   ```\n\n## 📊 API Endpoints\n\n### Core Notification API\n```http\nPOST   /api/v1/notifications           # Create notification\nGET    /api/v1/notifications/:id       # Get notification\nPATCH  /api/v1/notifications/:id       # Update notification\nGET    /api/v1/notifications           # List notifications\nPOST   /api/v1/notifications/batch     # Batch create\n```\n\n### User Preferences\n```http\nGET    /api/v1/preferences/:userId     # Get preferences\nPUT    /api/v1/preferences/:userId     # Update preferences\n```\n\n### Crisis Management\n```http\nPOST   /api/v1/crisis/alert           # Trigger crisis alert\nPOST   /api/v1/crisis/:id/acknowledge # Acknowledge crisis\nPOST   /api/v1/crisis/:id/escalate    # Escalate crisis\n```\n\n### WebSocket Events\n```javascript\n// Authentication\n{ \"type\": \"auth\", \"token\": \"jwt_token\" }\n\n// Subscribe to channels\n{ \"type\": \"subscribe\", \"channels\": [\"notifications\", \"crisis\"] }\n\n// Server events\n{ \"type\": \"notification\", \"data\": { ... } }\n{ \"type\": \"crisis_alert\", \"data\": { ... } }\n```\n\n## 🔧 Configuration\n\n### Key Environment Variables\n```bash\n#
